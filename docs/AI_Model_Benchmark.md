# 캐릭터 대화 AI — 모델·프롬프트 벤치마크 (2026-10-15)

환경: Intel Core Ultra 5 125H, RAM 16GB, Ollama 0.40.4, **CPU 전용**(GPU 적재 0%), num_ctx 4096
도구: `server/bench_models.py --prompt both` (서버와 같은 프롬프트로 측정, 케이스당 2회)

## 결과

| 모델 · 프롬프트 | 대사 1줄 | NPC 대화 묶음 (1회 호출) | 예전 방식 (4회 호출) | 존댓말 준수 (보정 전 → 후) |
|---|---|---|---|---|
| EXAONE 3.5 7.8B · 예전 프롬프트 | 13.9초 | 53.2초 | **54.9초 (기존 구조)** | 81% → 100% |
| EXAONE 3.5 7.8B · 압축 프롬프트 | 5.7초 | 26.1초 | 40.0초 | 50% → 88% |
| EXAONE 3.5 2.4B · 압축 프롬프트 | 3.3초 | 9.3초 | 18.2초 | 19% → 94% |
| **Qwen 3.5 4B · 압축 프롬프트 (채택)** | **4.3초** | **14.7초** | 36.3초 | 81% → 88% |
| Qwen 3.5 2B · 압축 프롬프트 | 3.2초 | 9.3초 | 26.7초 | 38% → 75% |

- 압축 프롬프트: 대사 프롬프트 715 → 208 토큰, NPC 대화 묶음 1,075 → 413 토큰 (EXAONE 토크나이저 기준)
- 보정 후 = 서버 후처리(반말 어미 → 존댓말, 괄호 지문·이모지·한자 제거, 긴 설명은 첫 문장만)를 적용한 값

## 결정

- 대사·판정 모두 **Qwen 3.5 4B + 압축 프롬프트**. 캐릭터 말버릇(세비-호의 자기 자랑, 진의 되묻기)이 가장 잘 살아났고,
  NPC 대화 묶음이 기존 구조 약 55초 → 약 15초(약 3.7배), 플레이어 대사 13.9초 → 4.3초(약 3.2배).
- 더 빠르게가 필요하면 EXAONE 3.5 2.4B (`SEVENS_MODEL=exaone3.5:2.4b`): 묶음 9초, 다만 말투가 일반적이고 설명이 길어지는 경향.
- 관찰: 작은 모델은 긴 규칙보다 짧은 카드 + 예시를 더 잘 따르지만(Qwen 4B 44% → 81%), 예시 문구를 그대로 반복하는 경향이 있어
  예시를 3개로 늘리고 "그대로 베끼지 말 것"을 추가함. EXAONE은 압축 시 반말이 늘어 후처리 보정이 필요.
